# Why each analysis decision was made

This is the decision record for the current release. Read the [case study](review_case.md) for the question and findings, and the [reproduction guide](reproducibility.md) for execution. Choices were made retrospectively during exploration and review. Recording them now makes them inspectable; it does not turn them into preregistered decisions.

| Decision | Why we chose it | Alternative and consequence | What a reader should check |
|---|---|---|---|
| Verify the original ZIP before loading | Prevent analyzing an HTML download page, a different release or edited files | Accept arbitrary files: greater flexibility but no assurance that the published results correspond to the same data | Loader SHA-256 and original [Dryad source](https://doi.org/10.5061/dryad.66t1g1k4j) |
| Preserve exported values and remove only trailing empty padding | Keep a reproducible baseline and avoid inventing missing samples | Fill gaps or delete peaks: changes the observed recording; internal gaps are rejected | 88 records, 22 participant IDs; no automatic signal repair |
| Treat people as independent observations | Two legs, conditions and many samples belong to the same person | Treat each sample or method as a patient: would exaggerate evidence | 44 participant-condition pairs do not mean 44 independent people |
| Retain both amplitudes alongside inv/uninv ratios | A large ratio can result from a small lower value, not a large upper value | Report only ratios: conceals their origin | Individual signals, numerator, denominator and record length |
| Present within-person comparisons first | Absolute voltages between people depend on acquisition and normalization | Compare absolute voltages as physiological activation: unsupported without references such as MVC | Absolute cross-person tests are supplemental; bilateral ratios still retain unequal sensor scaling |
| Compare 11 RMS and 21 total specifications | Expose dependence on explicit summary choices, including MAV as another amplitude measure | Choose the method with a preferred result: hides uncertainty introduced by processing | Whole RMS, p99.5-limited RMS, and blocks 256/512/1024 with thresholds q20 + f(q90−q20), f=0.1/0.2/0.3; count undefined variants separately |
| Select blocks separately for each leg | Makes the existing retrospective algorithm explicit and reproducible | Match contraction events: preferable for a different question but event boundaries are unavailable | Different subsets can be selected; block summaries do not necessarily estimate the same target as whole-record RMS |
| Subtract each recording's mean as a separate specification | Quantify how a constant component contributes to RMS without needing a sampling rate | Declare every mean an instrument artefact: would make an unsupported causal assumption | RMS² = centered RMS² + mean²; compare rather than overwrite the baseline |
| Estimate average sample rate from clock endpoints | Supplies an auditable rate for a conditional filtering sensitivity | Assume a manufacturer rate: requires acquisition evidence; use each duplicated interval as a rate: undefined | Finite, nondecreasing times and positive elapsed span; duplicates allowed. Endpoint agreement does not prove uniform sampling or explain duplicates |
| Use median estimated rate if relative spread is below 0.002 | Avoid silently applying one rate when clocks disagree | Individual rates or resampling: separate sensitivity choices; threshold is retrospective, not validated | Report minimum, maximum, median and spread; the check stops this filtering analysis if disagreement is larger |
| Apply 20–450 Hz filtering as sensitivity only | Examine attenuation under an explicit frequency response | Treat filtered data as recovered physiological truth: original device processing is unknown | SciPy Butterworth prototype N=4, SOS band-pass order 8 per pass; forward/backward effective order 16. Edge and transition attenuation are included |
| Report RMS retention, not “energy outside the band” | The computed value is RMS(filtered)/RMS(centered); its square compares mean squares | Integrate a spectral estimate to answer a frequency-energy question: a different method and assumptions | Values below 0.8 trigger review only. This heuristic identifies attenuation, not motion artefacts or the cause of a signal pattern |
| Set aside a pair if one record is below 25% of its cohort-condition median length | A short fragment and a longer exported task can represent different activity mixtures | Keep all pairs as primary: also report it; a different study could compare matched events if available | The rule was promoted to exclusion after inspecting data. Only healthy8/iso90 qualifies; 43 main pairs and all 44 in sensitivity, never delete the source |
| Show individual changes as well as medians and crossings of one | A stable group median can hide a changed individual ratio | Declare robustness from aggregate stability: misleading | healthy9/iso90 rises about 60% after filtering; 10 RMS crossings become 8. Numerical changes alone do not establish clinical importance |
| Keep fixed exploratory tests and family-specific Holm adjustment | Avoid choosing a test because it produces a desired p-value | Unadjusted multiple testing: more opportunities for chance findings | Shapiro is descriptive only; percentile bootstrap is over people, with uncertain small-sample coverage. Non-significance is not equivalence |
| Use synthetic reference scenarios | Known constructed targets reveal failure modes that observed signals alone cannot label | Treat simulated frequencies as clinical prevalence: unsupported | 11 scenarios × 100 seeded realizations × 21 methods; parameters are illustrative, shared carriers simplify bilateral signals |
| Keep external candidates separate | Their inspected exports cannot execute the same direct amplitude validation | Pool incompatible processed signals with Dryad: hides task and measurement differences | [Eligibility audit](history/external_validation_feasibility.md); no external validation claim |
| Generate notebook inputs from current source | Prevent an edited repository and an outdated delivery from appearing to be the same version | Maintain copied code manually: version drift | Archive SHA-256, executed notebook, source comparison and explicit local/Kaggle distinction |

No threshold in this table is a return-to-sport criterion. To change a decision, edit its named implementation, add a known-answer test, regenerate **all** outputs and record the change and rationale in [CHANGELOG](../CHANGELOG.md). A change of question or dataset requires an additional protocol, not simply reusing these thresholds.

Background: [CEDE normalization](https://doi.org/10.1016/j.jelekin.2020.102438), [processing decisions](https://doi.org/10.1016/j.jelekin.2016.10.001), [specification analysis](https://doi.org/10.1038/s41562-020-0912-z). Filter semantics: [SciPy butter](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.butter.html) and [sosfiltfilt](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.sosfiltfilt.html). These sources explain context and implementation; the project results are computed locally.
