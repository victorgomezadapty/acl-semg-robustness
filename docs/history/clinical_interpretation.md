# Clinical interpretation and limits

This portfolio studies what rehabilitation measurements can describe. It is not a clinical clearance system or a validated prediction model.

The source abstract describes dynamometry and vastus lateralis sEMG. Archive inspection confirms sEMG and time only; no torque or IMU channels are present. The README excludes accelerometer data and documents volts and seconds. Missing documentation must remain visible instead of being filled with presumed clinical meanings.

Return-to-sport assessment includes strength, movement/function, symptoms, psychological readiness, training exposure, sport demands and context. The project brief establishes this interpretive scope; these dimensions are not asserted to be measured by this dataset.

Symmetry must be displayed with absolute limb values. Similar values can coexist with low performance in both limbs, and contralateral strength should not automatically be treated as a healthy baseline. No LSI threshold will generate a ready-to-play label.

Do not infer recovery rate without repeated follow-up, prospective reinjury risk without outcomes, or clinical predictive performance from a small observational cohort. Any later dashboard is an exploratory rehabilitation profile visualization.
